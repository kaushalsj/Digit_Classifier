# Digit Classifier

A simple Digit Classifier project built using Python and NumPy.

## Description

This project implements a basic Neural Network from scratch to classify digits. It demonstrates forward propagation, activation functions, loss calculation, accuracy calculation, and result visualization.

## Technologies Used

* Python
* NumPy
* Matplotlib

## Features

* Forward Propagation
* ReLU Activation Function
* Softmax Output Layer
* Loss Calculation
* Accuracy Calculation
* Graph Visualization
